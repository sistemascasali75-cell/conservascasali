# Rediseño integral — Kardex Master Dashboard

## Objetivo
Aplicar a todo AlmaConserva una interfaz industrial clara inspirada en el archivo Kardex, sin cambiar datos, permisos ni procesos.

## Dirección aprobada
- Paleta: grafito `#252A2E`, gris operativo `#F2F4F3`, verde seguridad `#287D5B` y amarillo control `#E5B83B`.
- Tipografía: Sora para títulos y Manrope para contenido.
- Estructura: panel operativo con navegación lateral compacta.
- Composición: indicadores superiores, controles agrupados y tablas densas con jerarquía visual para entradas, salidas y saldos.

## Implementación
1. Renovar el sistema visual global: colores semánticos, tipografía, bordes, sombras, radios y densidad.
2. Rediseñar la navegación lateral y móvil con identidad AlmaConserva, secciones más compactas y estados activos claros.
3. Actualizar los componentes compartidos de tablas, botones, campos, tarjetas, pestañas y ventanas para que todas las páginas adopten el mismo lenguaje visual.
4. Rediseñar la pantalla de acceso con la misma identidad industrial clara.
5. Ajustar el Kardex como pantalla de referencia: encabezados agrupados, cifras tabulares, filtros y exportaciones claramente jerarquizados.
6. Verificar escritorio y móvil, navegación, formularios y tablas sin alterar la lógica existente.

## Límites
- El Excel se usa como referencia de estructura e información; no se importarán sus registros.
- No se modificará la base de datos, los cálculos, los roles ni los permisos.
